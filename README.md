# 🎓 EduNexus – Student Management System

EduNexus is a full-stack Student Management System designed to streamline student records, attendance tracking, fee management, and course administration through a modern and responsive web interface.

## 🚀 Live Demo

Frontend: https://edu-nexus-lilac.vercel.app/

Backend API: https://edunexus-backend-ps02.onrender.com

## 📌 Features

### Authentication
- User Registration
- User Login
- JWT Authentication
- Role-Based Access Control
- Protected Routes

### Student Dashboard
- Student Profile
- Attendance Progress
- Notifications
- Personal Task Manager
- Dark Mode Support

### Admin Dashboard
- Add Student
- Update Student
- Delete Student
- View Student Records
- Dashboard Analytics
- Recent Activity Section

### Attendance Management
- Mark Attendance
- View Attendance Records
- Attendance Statistics

### Fee Management
- Add Fee Records
- Track Fee Status
- View Payment Information

### Course Management
- Add Courses
- Manage Courses
- View Course Information

### UI Features
- Responsive Design
- Dark Mode
- Modern Dashboard UI
- Interactive Charts
- Glassmorphism Effects
- Mobile Friendly

- React Router DOM
- Axios
- Tailwind CSS
- React Icons

### Backend

- Express.js
- JWT Authentication
- bcryptjs

- MySQL

- Vercel (Frontend)
- Render (Backend)

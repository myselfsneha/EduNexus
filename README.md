## 💡 About EduNexus

College life comes with plenty of moving parts — student records, attendance, fees, courses, faculty, and timetables.

**EduNexus brings these academic workflows together in one place.**

It is a collaborative full-stack College Management System built with React, Node.js, Express.js, and MySQL, with a focus on practical academic management, role-based access, and a responsive user experience.

## 🚀 Run It Locally

### 1. Clone the repository

```bash
git clone https://github.com/myselfsneha/EduNexus.git
cd EduNexus
```

### 2. Set up the backend

```bash
cd backend
npm install
```

Create a local `.env` file with the database configuration and JWT secret required by the backend. Keep credentials private and out of version control.

Start the backend using the script defined in `backend/package.json`.

### 3. Set up the frontend

Open a separate terminal:

```bash
cd frontend/EduNexus
npm install
npm run dev
```

Open the local URL shown by Vite. Ensure the backend and database are configured and running correctly.
